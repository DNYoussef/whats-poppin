# Mobile dependency follow-up

On September 7, 2026, npm audit for the locked mobile package returned 10 moderate affected-package entries, all following the uuid advisory GHSA-w5hq-g745-h8pq (missing buffer bounds checking in v3/v5/v6 when a buffer is supplied). These are package-chain entries, not 10 distinct vulnerability disclosures. The raw result is mobile-dependency-audit.json; advisory: https://github.com/advisories/GHSA-w5hq-g745-h8pq.

Exposure through this app or its build tools has not been established. The inspected xcode 3.0.1 lib/pbxProject.js imports uuid at line 22 and calls v4() without a buffer at line 90. That call does not use the advisory's affected v3/v5/v6 buffer shape. Wider dependency-tree call paths were not exhaustively enumerated.

P00 now corrects the newly introduced native dependency with a mobile-only xcode -> uuid 11.1.1 override. The installed release rejects invalid buffer bounds before writing under D1's behavioral check, and its package exports retain CommonJS require support. The advisory linked above informed the version choice. Only the uuid package entry changed in the mobile lock; the root web lock remains unchanged. The override is declared under xcode, the sole declared dependent; the resulting install replaces the single hoisted uuid copy, also changing resolution for any undeclared consumers. The old 7.0.3 failed with "Missing expected exception (RangeError): v3: reject 8/0"; dependency-fail-first.txt binds the final test to the old-dependency reproduction. DEPENDENCY-GATES.md owns the correction's behavioral checks, clean-install compatibility, independent review and hosted native execution. Hosted success is recorded there and in dependency-hosted-runs.json.

mobile-dependency-audit-after.json records the fresh corrected mobile install's zero known npm advisories. This is scoped, time-dependent registry evidence, not a complete security audit. P09 still owns the broader application and full-tree security review. No Expo downgrade or forced audit fix was applied. Remove the override when an upstream xcode release declares a patched compatible dependency and the same gates pass.
